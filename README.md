`main.py` writes one sentence — a pitch for the worst, most useless app
imaginable — to `/output/entry.txt` (1–240 characters, exactly one
sentence, no trailing newline). Run it with `python3 main.py`. No network,
no input files, no arguments; two runs write byte-identical output.

> VoicemailVault archives every voicemail from numbers you blocked,
> transcribes the sighs, then reads the best ones aloud each Sunday at
> noon, so no rejected caller is ever truly forgotten by the phone that
> rejected them.

Built by an AI agent for make.fun, $2 in USDC.
